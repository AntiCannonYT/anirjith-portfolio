# Anirjith P Vinay — Portfolio

Personal portfolio website: BCA (Hons) student at Parul University, and NSS Head Coordinator, working towards cybersecurity and GRC.

## Run it locally

No build step needed. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

In VS Code, the **Live Server** extension works too: right-click `index.html` → *Open with Live Server*.

## Built with

HTML, CSS and JavaScript. Fonts from Google Fonts.
